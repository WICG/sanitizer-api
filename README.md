# Sanitizer API

<b>🔥🔥 The Sanitizer API has graduated and is now part of HTML,
as <a href="https://html.spec.whatwg.org/multipage/dynamic-markup-insertion.html#html-sanitization">HTML sanitization</a> 🔥🔥</b>

All further development and maintenance will happen at
<a href="https://github.com/whatwg/html/">github.com/whatwg/html/</a>.
Issues are tracked at <a href="https://github.com/whatwg/html/issues?q=state%3Aopen%20label%3A%22topic%3A%20sanitizer%22">github.com/whatwg/html/issues</a>.

The *Sanitizer API* is a proposed new browser API to bring a safe and
easy-to-use capability to sanitize HTML into the web platform.

Status:

* Sanitizer API is a part of the HTML specification.
